### Connors et al (2025)

Code used when reanalyzing TRAPPIST-1b, TRAPPIST-1c, LHS1478b, TOI1468b, and LHS1140c data.

Data can be obtained from MAST using the following DOI: [10.17909/h2e9-0j87](https://archive.stsci.edu/doi/resolve/resolve.html?doi=10.17909/h2e9-0j87).

Paper can be read here https://doi.org/10.48550/arXiv.2507.02052
